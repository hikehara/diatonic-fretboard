# ダイアトニック指板

ギターの指板を横向き（左がナット、右がブリッジ）に表示し、メジャーキーとマイナーキーのダイアトニックコード（メジャーなら Ⅰ・Ⅱm・Ⅲm・Ⅳ・Ⅴ・Ⅵm・Ⅶm(♭5)）の位置を確認するためのWebアプリです。

## 機能

- キー（メジャー12キー／マイナー12キー）、6弦ルート／5弦ルート、3和音／4和音（セブンス）の切り替え
- マイナーキーはナチュラルマイナーのダイアトニックコード（Ⅰm・Ⅱm(♭5)・♭Ⅲ・Ⅳm・Ⅴm・♭Ⅵ・♭Ⅶ）を表示
- 指板の表記を度数（Ⅱm など）とコード名（Dm など、選んだキーに合わせて変わる）で切り替え
- 表示範囲：開放弦〜12フレット（横スクロール）。キーやルート弦を切り替えると、ルート付近へ自動でスクロール
- コードの複数選択による強調表示、T／SD／Dでまとめて選択
- キー当てクイズ：キーを隠した指板を表示し、Ⅰ（Ⅰm）の位置からキーを12択で答える
- 選んだ設定は端末に保存
- オフライン動作（Service Worker）

## iPhoneのホーム画面に追加する

1. SafariでGitHub PagesのURLを開く
2. 共有ボタン →「ホーム画面に追加」

## ファイル

- `index.html`：アプリ本体（外部ライブラリ不要、1ファイル完結）
- `manifest.json`／`sw.js`：PWA設定とオフライン用キャッシュ
- `icon-*.png`／`apple-touch-icon.png`：アイコン
